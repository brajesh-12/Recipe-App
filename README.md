## Introduction

Built with React Native, this full stack Recipe App features Google Authentication, dynamic search, filters and smooth navigation. Powered by Neon for database and file storage, it delivers a responsive, scalable, and modern user experiences.

## Backend Info: 

**Neon** : Used to create database for our app. The database is related to the recipes saved by user.

**Drizzle** : Used this to connect database and execute queries.

## Fontend Info: 

**Expo** : Used Expo for building this Recipe app, it is an open-source platform for building native apps using JavaScript, TypeScript and React Native. This provides feature like expo-router, fast refresh, native modules for camera/maps/nopitifications, over-the-air updates (EAS), and streamlined app deployment.

**Clerk** : We used Clerk to implement authentication in our Recipe app.

**TheMealDB** This is an open and crowd-sourced database of recipes. We used this to get recipes and display it on our app.

## Features

**GoogleAuthentication**: Secure and seamless user sign-ins using Google.

**Home Screen**: Showcase different recipes, and give users filter option to filter the recipes based on category.

**Search Screen**: Let users search any recipe by category, name and ingredients.

**Recipe Detail Screen**: Provides information related to recipe like, ingredients, instructions and also provide video of recipe.

**Favourites Screen**: Users saved recipes display here.
